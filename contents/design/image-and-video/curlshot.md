Hosted remote MCP server that lets Claude Code, Codex, Cursor, Gemini CLI and other MCP clients take screenshots of web pages. The `take_screenshot` tool renders a public URL as an image the model can see (PNG, JPEG or WebP), a PDF, or a video of the page scrolling, with full-page capture, device presets, dark mode and single-element capture by CSS selector.
