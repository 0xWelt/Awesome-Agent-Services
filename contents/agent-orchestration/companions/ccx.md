ccx pairs a Claude Code session with a Codex thread and syncs context both ways: messages, condensed tool calls, the latest plan and git status. When one side hits its usage limit, click ⇄ in the macOS menu bar and the other continues the task; each update is delivered once, and it warns when either side's 5-hour window passes 90%.
