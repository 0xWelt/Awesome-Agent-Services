LynxPrompt is a self-hosted web app that turns one set of AI coding rules into the file each tool reads: `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/`, Copilot instructions, 30 rule-file formats in all. A wizard writes the rules from your stack, blueprints let a team share them with variables, and the `lynxp` CLI and a VS Code extension put the files into every repository.
