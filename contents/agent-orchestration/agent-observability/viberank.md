viberank is a public leaderboard and open dataset for AI coding spend. It reads the same local ccusage session data that other observability tools use — across Claude Code, Codex, Gemini CLI, Copilot, OpenCode and more — and aggregates it into a comparison rather than a local dashboard, so you can see whether your usage is normal rather than just what it was.
